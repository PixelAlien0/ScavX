## Overview

ScavX introduces an extensive overhaul to Beyond All Reason scavenger gameplay, tactical AI squad behaviors, 27 custom cloned units and superweapons, and constructor buildmenu expansions:

1. **Scavenger AI Squad Behaviors**: Custom anger thresholds (40% - 90%), engagement radiuses, unit counts, and special squad roles (`Raider`, `Berserk`, `Artillery`, `Kamikaze`).
2. **27 Custom Cloned Units**: Heavy experimental weapons, overdriven plasma fortresses, walking titans, long-range sniper cannons, high-power defense shields, and economic generators.
3. **Buildmenu Integration**: Custom unit clones injected directly into Arm, Core, and Legion construction units (ACA, ACK, ACSUB, ACV, Commanders, T3 Builders, and Everything Experimental).
4. **EditP Studio Integration**: Full two-way project synchronization with [EditP](https://edit-p-nine.vercel.app/) via `scavx.editp.json`.
